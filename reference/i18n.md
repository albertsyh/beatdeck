# Languages

Copy lives in `src/strings/<tag>.js`, one plain-data module per language, all the
same shape. `src/strings/index.js` runs the shape guard **at import**, and
`build.mjs` imports it before bundling, so drift is a build error naming the path:

```
[strings:th] missing key close.takeaway
[strings:zh-Hans] points.items has 2 entries, the default language has 3
```

Array length is load-bearing: it is a slide's step count.

## Adding a language

1. Copy `en.js` to `<tag>.js` (BCP 47: `zh-Hans`, `th`, `de`, `pt-BR`) and translate
   every string. No empty strings; `**`, `_ _`, `[[ ]]` and `\n` markers work the same.
2. Register it in `src/strings/index.js`:
   ```js
   import zh from "./zh-Hans.js";
   export const { … } = defineLanguages({ en, "zh-Hans": zh }, { defaultLang: "en", order: ["en", "zh-Hans"] });
   ```
3. Add its name to `ui.langNames` / `ui.langFull` in **every** language file (the
   switcher shows every language's name in every language; the guard requires it).
4. If it needs a non-Latin script, list the preset in `deck.config.js fonts.scripts`
   and run `bun run fonts:subset` (needs `.venv`, see below). Latin-script languages
   need nothing — the Latin subset already covers them. Vietnamese needs
   `subsets: ["latin", "vietnamese"]` on the family in `fonts.families`.
5. `bun run build` → `bun run check:layout`. Fix overflow with a `:root[lang="<tag>"]`
   token override in `src/deck.css`, or shorter copy.

The switch appears in the chrome automatically once there is more than one language
(`L` cycles it). On a phone it collapses to one button that keeps the width of the
widest name.

## Font subsetting

```bash
python3 -m venv .venv && .venv/bin/pip install "fonttools[woff] brotli"
bun run fonts:subset      # → src/fonts-scripts.css (commit it)
```

Subsets each script face to exactly the characters in `allText()` minus what the
Latin faces carry, so a deck's Chinese copy costs ~100 KB instead of 17 MB. The
`unicode-range` in the output is computed from the subset, so shared punctuation
stays in the deck's own face. Source faces are cached in `tools/.fontcache/`.

**Re-run after any change to non-Latin copy.** Forgetting fails the build by name
(`"门" U+95E8 is not covered by any embedded font`) — it will not ship a tofu box.

Presets (`tools/script-faces.mjs`): `sc` `tc` `jp` `kr` `thai` `arabic` `devanagari`.
A custom face is `{ family, file, url, pin? }` pointing at a TTF (OFL or licensed).

## Per-language metrics

`base.css` retunes tokens for Thai (looser leading, zero tracking) and CJK (zero
tracking, wrap anywhere). Add more under `:root[lang="…"]` in `src/deck.css`. Only
metrics — never copy, never layout structure, never viewport units.

## Preferences

`?lang=th&theme=dark#4.2` opens in Thai, dark, on slide 4 beat 2. Precedence: query
string > `localStorage` > `deck.config.js` default. The pref is stamped on `<html>`
before React mounts, so the first paint is right. Storage keys are namespaced by
deck name because Chrome treats every `file://` page as one origin.
